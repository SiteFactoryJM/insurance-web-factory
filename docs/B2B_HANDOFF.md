# 보험사·GA·지사 제안용 범위와 인수 기준

## 구매자에게 설명할 핵심

조직의 담당자 소개 페이지를 같은 운영 기준으로 만들되, 목적에 맞는 원고를 선택하고 개인별 연락처를 연결하는 **관리형 제작 기반**입니다. 입력 부담을 줄이는 선택형 제작과 제작자용 상세 편집을 분리합니다.

첫 시연은 `/proposal` → `/studio`에서 목적 선택 → 실제 정보 입력 → 페이지 미리보기 → 제작 JSON 전달 순서가 적합합니다. 상담 문의는 온라인 접수 대신 전화와 오픈채팅을 사용합니다. 연락 후 고객 응대는 실제 담당자가 수행합니다.

## 구현 범위

전화·오픈채팅 링크, 114개 원고 선택지, 8개 목적 구성, 기존 5개 레이아웃/6개 팔레트, JSON 교환, 명시적 기기 내 초안 저장, 기존 자유 편집, 예시 후기 비노출, 운영 전 검토 상태 확인이 포함됩니다.

문구를 고르는 행위가 심의 승인을 의미하지 않습니다. 특정 상품의 취급 가능 여부·무료 제공·응답 시간·경력·성과는 자동으로 보증하지 않습니다. 조직의 실제 제공 범위와 맞지 않는 샘플은 수정하거나 제외해야 합니다.

## 포함되지 않는 기능

카카오톡 자동 메시지·알림톡·웹훅, 고객 온라인 신청서·DB 수신함·CRM, 상품 추천/보험금 자동 진단, 온라인 가입, 로그인·역할별 관리자 권한·전자결재, 자동 게시, 상담 완료·계약 실적 집계는 제공하지 않습니다.

## 인수 전 확인할 것

- 최신 소스에서 `npm run check`와 모든 Playwright 테스트가 통과해야 합니다.
- 현재 실제 연락처와 오픈채팅방 연결을 담당자 기기로 확인해야 합니다.
- 주요 화면의 실제 캡처에서 모바일 줄바꿈·하단 버튼·키보드 포커스·사진 비율을 확인해야 합니다.
- 신규 원고가 실제 제공 범위를 벗어나지 않는지 소속 조직이 확인해야 합니다.
- 새 담당자 작업에 기존 데모의 이름·사진·연락처·후기가 남아 있지 않아야 합니다.
- 자유 편집 → 선택형 파일 교환에서도 사용자 원고·이미지·선택 배치가 보존되어야 합니다.
- 이전 API로 요청하더라도 저장/발송 없이 HTTP 410이어야 합니다.

위 목록은 인수 기준입니다. 이 문서의 존재만으로 검증이 완료되었다고 주장하지 않습니다. 현재 작업의 실제 수행 결과는 함께 제공된 `VALIDATION.md`를 기준으로 판단합니다.
