# 제작 화면 가이드

제작 화면은 `/studio` 하나이고, `나가기 · 메인으로`를 누르면 언제나 메인(`/`)으로 돌아옵니다. 가로 768px 미만에서는 제작 화면이 열리지 않고 안내만 보입니다. 페이지를 만들면서 완성 화면을 옆에 두고 비교해야 하기 때문입니다.

## 1. 디자인과 문구

`/studio`의 첫 단계에서 5가지 화면 구성과 6가지 색상을 서로 독립적으로 고르고, 같은 화면 아래에서 문구까지 고릅니다. 구성이나 색상을 바꿔도 이미 고른 문구는 그대로 남습니다. 기존 보험 점검, 새 가입 준비, 가족 보험 안내, 생활 변화 점검, 장기 유지·은퇴 준비, 자영업·직장 생활, 소개 고객 안내, 조직 표준 소개는 접힌 ‘목적별 추천 구성’에서 선택할 수 있습니다.

목적에 맞는 문구와 구성을 한 번에 적용하고, 색상을 바꿀 수 있습니다. 다른 목적을 고를 때 입력한 담당자 정보는 유지합니다. 추천을 적용하면 문구·구성은 교체되므로 안내를 확인하세요.

어느 단계에서든 왼쪽 `크게 보기`를 누르면 실제 크기 화면이 전체 화면으로 열리고, 오른쪽 위 ✕ 또는 Esc로 닫으면 보던 단계로 돌아옵니다.

### 문구 고르기

| 범주 | 선택지 | 적용 방식 |
| --- | ---: | --- |
| 첫 화면 | 24개 | 제목·설명·모바일 원고 함께 적용 |
| 담당자 소개 | 16개 | 소개 제목·본문·모바일 원고 함께 적용 |
| 상담 분야 | 24개 | 3~6개 선택 후 묶음 적용 |
| 상담 과정 | 8세트 | 3개 단계의 한 세트 적용 |
| 자주 묻는 질문 | 30개 | 2~8개 선택 후 묶음 적용 |
| 하단 안내 | 12개 | 추가 안내 문장 적용 |

총 114개 선택지입니다. 검색으로 문구를 좁힐 수 있습니다. 선택지는 원고의 출발점이며 실제로 제공하지 않는 상담 분야는 선택하지 마세요. 자동으로 경력·고객 후기·매출·절감률·무료 상담을 추가하지 않습니다.

## 2. 실제 정보

이름·직함·소속, 전화번호, 카카오톡 오픈채팅 초대 주소, 실제 상담 시간을 입력합니다. 프로필 사진과 등록 정보·주소는 준비된 사실만 입력합니다. 새 작업에는 예시 담당자의 정보가 자동으로 복사되지 않습니다. ‘예시 담당자 정보로 채워 보기’는 확인 후 실행합니다.

전화 버튼은 `tel:`로, 오픈채팅 버튼은 해당 초대 주소로 연결됩니다. 편집 화면에서는 외부 연결을 실행하지 않으므로 최종 게시 후 실제 기기에서 확인하세요. 미리보기는 고객용 페이지와 똑같이 그려지지만 실제 기기의 카카오톡 설치·로그인 상태까지 재현하지는 않습니다.

‘쓰고 싶은 주소’는 적어 두는 칸일 뿐 구매·연결되지 않습니다. 저장 전에는 실제 취급 범위·원고, 연결 대상, 사진 사용권 등을 확인합니다.

## 3. 확인하고 저장

### 초안 저장 및 시연

먼저 `초안 저장 및 시연`을 누릅니다. 지금까지 입력한 이름·연락처·사진이 그대로 들어간 실제 크기 화면이 전체 화면으로 열리고, 같은 내용이 이 브라우저에 보관됩니다. 아직 비어 있는 항목이 있으면 함께 알려 줍니다. ✕ 또는 Esc로 닫습니다.

### 파일로 내보내기

실제 취급 범위, 전화·카카오톡 연결 대상, 사진·로고 사용 권한 세 가지를 확인하면 `파일로 내보내기`가 동작합니다. 확인란은 조직 승인이나 법적 심의를 대체하지 않으며 내용을 바꾸면 다시 확인해야 합니다. 내보내기는 현재 화면을 하나의 스냅샷으로 고정해 인쇄용 화면과 다시 불러올 작업 파일을 만듭니다.

## 저장·복원

`파일로 내보내기`는 압축 파일 하나를 내려받습니다. 안에는 인쇄용 화면 1개와 작업 파일 1개만 들어 있습니다. 이름은 `만든날짜-담당자이름` 형식이라(예: `20260917-이윤복.zip`) 받는 사람이 목록에서 바로 알아볼 수 있습니다. 사진은 JPG·PNG·WebP 파일당 3MB 이하, 작업 파일은 8MB 이하, 인쇄본은 20MB 이하, 압축 파일은 30MB 이하입니다. 내보내려면 유효한 전화번호와 오픈채팅 주소가 필요합니다. 예전 형식의 작업 파일도 불러와 이어갈 수 있으며, 읽지 못하면 지금 만들던 내용은 그대로 둡니다.

압축 파일은 풀지 말고 지정된 제작 담당자에게 전달합니다. 자동 공개, 카카오톡 발송, 서버 업로드는 하지 않습니다. 고른 구성과 문구가 작업 파일에 담기므로 나중에 다시 불러와 이어서 고칠 수 있습니다.

‘이 컴퓨터에 작업 내용 임시 보관’은 기본 꺼짐이고, `초안 저장 및 시연`을 누르면 켜집니다. 켜져 있을 때만 현재 브라우저에 작업 내용을 남깁니다. 여러 사람이 쓰는 PC에서는 끄세요. ‘되돌리기’와 ‘지우기’가 있으며 보관을 끄면 남아 있던 내용을 지웁니다. 다른 기기와 동기화되지 않고 브라우저를 정리하면 사라지므로 파일로도 내보내 두세요.

인쇄 버튼은 지금 만들고 있는 페이지의 인쇄 창을 엽니다. 아직 비어 있는 항목이 있을 수 있으므로 확인용으로 사용합니다.
