# 선택형 제작 가이드

## 1. 배치·색상

`/studio`에서 5가지 배치와 6가지 색상을 서로 독립적으로 고릅니다. 기존 보험 점검, 새 가입 준비, 가족 보험 안내, 생활 변화 점검, 장기 유지·은퇴 준비, 자영업·직장 생활, 소개 고객 안내, 조직 표준 소개는 접힌 ‘목적별 추천 구성’에서 선택할 수 있습니다.

목적에 맞는 문구와 레이아웃을 한 번에 적용하고, 팔레트를 바꿀 수 있습니다. 다른 목적을 고를 때 작성한 담당자 정보는 유지합니다. 추천 구성을 적용하면 문구·배치는 교체되므로 안내를 확인하세요. 상세 배치·순서·서체는 `/studio/advanced`에서 조정합니다.

## 2. 문구 선택

| 범주 | 선택지 | 적용 방식 |
| --- | ---: | --- |
| 첫 화면 | 24개 | 제목·설명·모바일 원고 함께 적용 |
| 담당자 소개 | 16개 | 소개 제목·본문·모바일 원고 함께 적용 |
| 상담 분야 | 24개 | 3~6개 선택 후 묶음 적용 |
| 상담 과정 | 8세트 | 3개 단계의 한 세트 적용 |
| 자주 묻는 질문 | 30개 | 2~8개 선택 후 묶음 적용 |
| 하단 안내 | 12개 | 추가 안내 문장 적용 |

총 114개 선택지입니다. 검색으로 문구를 좁힐 수 있습니다. 선택지는 원고의 출발점이며 실제로 제공하지 않는 상담 분야는 선택하지 마세요. 자동으로 경력·고객 후기·매출·절감률·무료 상담을 추가하지 않습니다.

## 3. 실제 정보

이름·직함·소속, 전화번호, 카카오톡 오픈채팅 초대 주소, 실제 상담 시간을 입력합니다. 프로필 사진과 등록 정보·주소는 준비된 사실만 입력합니다. 새 작업에는 실제 데모 담당자의 정보가 자동으로 복사되지 않습니다. ‘데모 정보 가져오기’는 확인 후 실행합니다.

전화 버튼은 `tel:`로, 오픈채팅 버튼은 해당 초대 주소로 연결됩니다. 편집 화면에서는 외부 연결을 실행하지 않으므로 최종 게시 후 실제 기기에서 확인하세요. 미리보기는 고객용 페이지와 같은 렌더러를 사용하지만 실기기의 카카오톡 설치·로그인 상태까지 재현하지 않습니다.

희망 도메인은 선택 정보이며 구매·연결되지 않습니다. 저장 전에는 실제 취급 범위·원고, 연결 대상, 사진 사용권 등을 확인합니다.

## 4. 검토·초안 저장

실제 취급 범위, 전화·오픈채팅 연결 대상, 사진·로고 사용 권한을 확인합니다. 확인란은 조직 승인이나 법적 심의를 대체하지 않으며 내용을 바꾸면 다시 확인해야 합니다. `초안 저장 · ZIP`은 현재 화면을 하나의 스냅샷으로 고정해 검토용 PDF와 다시 편집할 JSON을 만듭니다.

## 저장·복원

‘초안 저장 · ZIP’은 PDF 1개와 JSON 1개를 다운로드합니다. 사진은 JPG·PNG·WebP 파일당 3MB 이하, JSON은 8MB 이하, PDF는 20MB 이하, ZIP은 30MB 이하입니다. 저장 시 유효한 전화번호와 오픈채팅 주소가 필요합니다. v1·v2 JSON을 불러와 이어갈 수 있으며 검증 실패 시 기존 편집 내용은 유지합니다.

ZIP은 압축을 풀지 말고 지정된 제작 담당자에게 전달합니다. 자동 공개, 카카오톡 발송, 서버 업로드는 하지 않습니다. 선택한 레이아웃과 문구가 JSON에 담기므로 자유 편집에서 다시 불러와 세부 조정할 수 있습니다. PDF는 디자인과 전체 원고를 검토하는 문서입니다.

‘기기에 초안 보관’은 기본 꺼짐입니다. 켠 경우에만 현재 브라우저의 로컬 저장소에 초안을 보관합니다. 공용 PC에서는 사용하지 마세요. ‘복원’과 ‘삭제’가 있으며 보관을 끄면 저장된 초안을 삭제합니다. 다른 기기와 동기화되지 않으며 브라우저 정리 시 사라질 수 있습니다. JSON도 별도로 보관하세요.

인쇄 버튼은 현재 선택한 페이지의 인쇄 창을 엽니다. 미완성 정보가 있을 수 있으므로 검토본으로 사용합니다. 전용 인쇄 의뢰서가 필요한 경우 자유 편집의 PDF 저장을 사용하세요.

## 자유 편집

`/studio/advanced`는 기존 상세 편집 기능을 보존합니다. 6개 제목 서체, 섹션별 패턴·순서·표시, PC/모바일 원고, 사진, 연락처·고지, 제작 파일 저장을 제공합니다. 기존 ‘하단입력’ 명칭은 ‘연락처·고지’로 정리했습니다. 고객용 설문 편집은 제거했고, 전화·오픈채팅 버튼 문구는 행동을 오해하지 않도록 고정했습니다.

자유 편집은 계정이나 역할로 잠긴 관리자 도구가 아닙니다. 조직에서 누가 원고를 수정하고 승인할지 운영 절차로 정해야 합니다.
