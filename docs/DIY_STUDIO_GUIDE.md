# ATELIER DIY 제작 가이드

대표 예시 `/`에서 완성된 페이지를 보고, 최상단 **내 페이지 만들기**로 `/studio`를 엽니다. 상담 신청 체험과 페이지 편집은 별도 화면입니다.

## 작성 순서

1. **스타일·구성**: 컬러, 명조/고딕 제목, 섹션별 배치, 배경 디테일, 여백을 고릅니다. 각 섹션은 다른 섹션과 독립적으로 선택합니다. 화살표로 순서를 바꾸거나 체크를 해제해 숨길 수 있습니다. 푸터와 고지는 항상 남습니다.
2. **프로필·문구**: 이름·소속·사진과 PC/모바일 원고, 상담 분야, 진행 과정, FAQ, 후기, 상담 설문 주제를 작성합니다. **예시 사용**은 해당 그룹의 내용을 실제 입력값으로 가져옵니다. 상단 **예시로 시작**은 선택한 스타일을 유지하고 전체 원고를 가져옵니다.
3. **푸터**: 제목·추가 안내·소속·등록번호·주소·전화·이메일·상담시간·보험 고지·개인정보 안내를 수정합니다. 클래식 양단, 소개/소속/연락처 세 단, 중앙 정렬 중 선택합니다.
4. **저장**: **제작 파일 저장**으로 JSON을 다운로드합니다. **파일 불러오기**로 사진과 원고, 구성 선택을 복원할 수 있습니다. **PDF로 저장**은 인쇄 창을 열며, 인쇄 대상에서 PDF를 선택합니다.

처음 편집값은 빈 원고이며 미리보기에는 참고용 예시를 보여줍니다. ‘예시로 시작’을 눌러야 전체 예시가 편집 내용으로 들어갑니다. 직접 입력을 시작하면 미리보기는 자신의 원고로 바뀝니다. 기존 원고를 예시나 다른 파일로 교체할 때 확인창을 표시합니다.

## 고를 수 있는 패턴

| 대상 | 선택 |
| --- | --- |
| 첫 화면 | 풍경과 여백 / 인물 중심 / 메시지 중심 |
| 상담 분야 | 번호 목록 / 분야별 카드 / 두 단 구성 |
| 소개 | 읽는 소개 / 프로필 소개 / 상담 원칙 인용 |
| 과정 | 단계 안내 / 세로 타임라인 |
| FAQ | 접고 펼치기 / 펼친 두 단 목록 |
| 푸터 | 클래식 / 정보 세 단 / 간결한 정렬 |
| 디테일 | 가는 선 / 은은한 격자 / 장식 없음 |
| 여백 | 넉넉하게 / 단정하게 |

컬러는 따뜻한 중립 배경을 공통으로 사용하며 포레스트·웜스톤·네이비·차콜·슬레이트·딥 틸의 강조색을 제공합니다. PC 미리보기는 1440px, 모바일은 390px 화면을 작업 공간에 맞게 축소해 보여줍니다.

| 메인 제목 | 40자 | 24자 |

공백·줄바꿈과 이모지 한 문자를 각각 한 글자로 셉니다. 초과한 문구를 임의로 자르지 않고 저장 전에 오류로 안내합니다. 모바일 원고를 비우면 PC 원문을 사용합니다. 고지와 개인정보 안내에는 모바일 축약을 적용하지 않습니다.

## JSON과 PDF의 역할

JSON은 다시 편집하거나 개인별 사이트를 만들기 위한 원본입니다. `format: insurance-web-factory/diy`, `version: 1`, `savedAt`, `site`를 담습니다. 업로드한 사진은 파일 내부에 포함됩니다. JPG·PNG·WebP 사진 한 장은 3MB 이하, 전체 제작 파일은 8MB 이하입니다. 기본 제공 이미지는 프로젝트 내 자산 경로로 유지됩니다.

PDF는 선택한 디자인, 섹션 순서·숨김, 프로필·사진, PC/모바일 원고, 상담 설문 주제, 푸터와 고지를 검토하는 제작 의뢰서입니다. 편집 복원에는 JSON도 함께 보관합니다.

DIY 편집값은 서버나 브라우저 저장소에 자동 저장하지 않습니다. 사용자가 저장 버튼을 누른 경우에만 자신의 기기로 파일을 다운로드합니다. 상담 체험 입력은 이 파일에 포함되지 않으며 계속 미전송·미저장입니다.

## 받은 파일로 설계사별 사이트 만들기

```bash
npm run studio:import -- --file ./incoming/김서연-상담페이지.json --id kim-seoyeon
npm run check
npm run preview
```

검증된 입력만 `sites/kim-seoyeon/site.json`에 반영합니다. 업로드 이미지는 `public/sites/kim-seoyeon/`에 파일로 추출하고 참조 경로를 바꿉니다. 원본 파일이 이미 있으면 중단하며, 명시적으로 교체할 때만 `--force`를 사용합니다. `src/generated/sites.generated.ts`는 `npm run generate`로 생성합니다.

가져온 설정은 항상 `draft`, `noIndex: true`, 데모 미전송 상태이며 도메인과 게시 확인은 초기화됩니다. 실제 운영 정보·고지·사진 권한을 확인한 후 기존 게시 절차를 적용합니다. 제작 파일을 불러오는 것만으로 공개되거나 상담 전송이 켜지지 않습니다.

## 대표 예시 이미지 출처

`public/assets/atelier-interior.webp`는 이번 작업에서 ImageGen으로 만든 장식용 실내 이미지입니다. 실제 설계사의 사무실이나 상담 장소를 촬영한 사진이 아닙니다. 외부 레퍼런스의 사진·로고·독점 서체를 복제하지 않았습니다. 설계사 프로필은 기존 제공 사진을 유지합니다.

생성 프롬프트의 핵심: “Photorealistic editorial architecture photograph for a premium Korean insurance advisory website. Quiet private consultation lounge, warm limestone, dark walnut, soft ivory seating, tall windows with natural afternoon light, restrained greenery, contemplative refined atmosphere. No people, no lettering, no logos, no visible documents. Warm neutral palette with subtle deep forest accents. Landscape 3:2 composition, rich natural material texture, understated luxury.”
