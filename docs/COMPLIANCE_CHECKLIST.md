# 준법·개인정보 체크리스트

이 문서는 개발 체크리스트이며 법률 또는 준법 자문을 대체하지 않습니다. 실제 공개 기준은 설계사의 소속 보험사·GA와 담당 준법 부서에서 확정합니다.

## 게시 전 필수 확인

- 설계사 이름·소속·지점·등록번호가 현재 정보와 일치
- 경력·수상·교육·자격 표현의 증빙과 사용 승인 확보
- 사진·로고·후기·이미지의 홈페이지 사용권 확보
- 특정 상품·보험료·보장·절세 효과 관련 표현의 심의 여부 확인
- 광고심의 번호·유효기간·고지 문구가 승인본과 일치
- 과장, 확정, 비교우위, 오인 가능 표현 제거
- 개인정보·외부 연결 안내의 담당자와 실제 호스팅 운영 기준 확인
- 전화·오픈채팅으로 이동한 뒤 적용되는 담당자·외부 서비스의 처리 기준 확인
- 공개 오픈채팅에 주민등록번호·병력·계약서 원본을 남기지 않도록 안내
- 사이트별 `publicationConfirmed`, `photoUseConfirmed`, `contentTruthConfirmed` 확인

## 데모 페이지 원칙

- 실제 담당자의 이름·사진·소속·연락처를 사용하는 데모임을 명확히 표시
- 전화와 오픈채팅 버튼이 실제 담당자에게 연결된다는 사실을 버튼을 누르기 전에 안내
- 공개 페이지에 필요한 담당자 정보만 표시하고 사진·연락처 사용 권한을 확인
- 특정 상품을 홍보하지 않음
- 고객용 입력 폼을 제공하지 않고 전화·오픈채팅으로만 연결
- 페이지가 고객의 상담 내용을 저장·자동 전송하지 않음
- `noindex`와 `robots.txt Disallow` 적용

## 운영 중 변경

문구·사진·소속·심의번호를 변경할 때는 단순 콘텐츠 수정으로 보지 않고 재검수 대상으로 관리합니다. 승인된 문구와 실제 게시본의 스크린샷 또는 배포 커밋을 함께 보관하는 방식을 권장합니다.
