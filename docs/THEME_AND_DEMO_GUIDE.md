# 화면 구성·색상과 데모 안내

데모는 다음 5개 화면 구성을 유지합니다.

- `/?theme=trust-blue`
- `/?theme=warm-care`
- `/?theme=premium-navy`
- `/?theme=clean-minimal`
- `/?theme=local-friendly`

페이지 상단의 디자인 선택에서 화면 구성과 6개 색상을 고를 수 있습니다. 두 값은 독립적으로 적용되며 `/?theme=warm-care&palette=stone`처럼 주소로도 확인할 수 있습니다. `/templates`에서는 한 색상으로 5개 구성을 비교합니다. 이 선택은 데모 URL에만 반영되며 고객 정보를 저장하지 않습니다.

사이트 원본의 `template`은 화면 구성, `palette`는 색상입니다. `palette`가 없으면 구성별 기본 팔레트를 사용합니다. `templateContent`에는 구성별 제목, 설명, 상담 분야, 상담 과정, FAQ와 강조 내용을 둘 수 있습니다. 운영 사이트에서는 설정된 구성만 사용하며 URL 전환은 `demo.enabled`와 `demo.allowTemplateSwitch`가 모두 참일 때만 허용됩니다.

고객 페이지에는 실제 설정된 전화번호의 `tel:` 링크와 카카오톡 오픈채팅 초대 링크가 표시됩니다. 전화번호는 PC에서도 확인할 수 있도록 텍스트로 함께 보여 줍니다. 고객 입력 폼, 이메일 접수, 자동 카카오톡 전송, 브라우저 저장은 제공하지 않습니다. 미리보기에서는 외부 연락 링크를 실행하지 않습니다.

제작 화면은 `/studio` 하나이며 디자인과 문구 → 실제 정보 → 확인하고 저장의 3단계입니다. 구성이나 색상을 바꿔도 고른 원고와 입력한 담당자 정보는 유지됩니다. `초안 저장 및 시연`은 현재 브라우저에서 큰 화면을 확인하고, `파일로 내보내기`는 인쇄본과 다시 불러올 작업 파일을 담은 ZIP을 만듭니다. 어느 동작도 자동 게시나 외부 전송을 하지 않습니다.

기본 글자는 본문 18px, 보조 16px입니다. 모바일 원고는 650px 이하에서 표시하고, 별도 모바일 원고가 없으면 PC 원문을 모두 표시합니다. 세부 색상과 반응형 규칙은 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md), 전화·오픈채팅 제한은 [KAKAO_INTEGRATION.md](KAKAO_INTEGRATION.md)를 참고합니다.
