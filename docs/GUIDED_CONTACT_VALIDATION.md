## 통합 과정에서 수정한 문제

- 본문 바로가기를 샘플 도구막대보다 먼저 배치해 첫 Tab 이동 복구.
- 제작 파일과 사이트 원본의 전화번호 검증을 실제 링크 생성 규칙과 일치시킴.
- 선택형 편집에서 가져온 하단 제목·SEO 제목을 자동으로 덮어쓰던 동작 제거. 사용자 원고·이미지·숨긴 섹션 보존 회귀 검사 추가.
- 320px에서 글자를 200% 확대하면 연락처 영역이 가로로 넘치던 문제 수정.
- 선택형 제작기의 모바일 로고 줄바꿈 수정.
- 선택 해제에 따라 대상이 바뀌던 테스트 locator 수정. 외부 폰트 지연과 편집기 준비 상태를 분리하되 6종 실제 폰트 로딩 검사는 유지.
- 새 제작기 생성 번들을 `.gitignore`에 추가. 사이트 레지스트리는 `npm run generate`로 생성.

## 확인 범위의 한계

실제 담당자에게 전화하거나 메시지를 발송하지 않았다. 통화 앱 실행, 카카오톡 로그인 및 오픈채팅방의 실제 소유자·활성 상태는 이 자동 검사로 확인하지 않는다. 조직의 광고심의·게시 승인을 생성하지 않으며 초안 저장과 공개는 구분한다.

이 문서는 로컬 통합 검증 기록이다. 원격 CI, PR 병합, Cloudflare 배포 결과는 PR #7 및 해당 Actions 기록에서 별도로 확인한다. 배포 확인은 `scripts/verify-live.mjs`로 새 버전·30개 조합·두 제작기·직접 연락·API 410을 검사한다.
