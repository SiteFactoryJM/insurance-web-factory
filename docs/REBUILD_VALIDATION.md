# Clear Human 리빌딩 검증 기록

검증일: 2026-09-17. 브랜치: `codex/clear-human-rebuild`.

## 자동 검증

- 변경 전 `npm run check`: 199개 단위 테스트 통과.
- 변경 후 `npm run check`: 사이트 1개, 도메인 0개, 오류·경고 0개, 타입 검사 성공, 202개 단위 테스트 통과.
- `npm run test:e2e`: 37개 Playwright 시나리오 전체 통과(약 5분). 30개 배치·색상 조합, 고객 페이지, 4단계 Studio, 자유 편집, 5개 화면폭, 200% 글자 확대, 접근성, 실제 ZIP/PDF 다운로드를 포함한다.
- 전체 실행 중 320px·200% 확대에서 Studio 로고가 15px 넘치는 문제를 발견해 줄바꿈을 허용했고, 해당 테스트와 전체 37개를 다시 실행해 통과했다.

## 실제 ZIP·PDF 검증

- Chromium에서 실제 `download` 이벤트를 받아 ZIP을 열었다.
- 루트 파일은 PDF 1개와 JSON 1개뿐이다.
- JSON v2, `clear-human-v1`, 초안 ID, `draft`, `noIndex`, 문의 폼 비활성 상태를 확인했다.
- `pdf-lib`으로 PDF를 다시 열었고 21페이지를 확인했다.
- PDF.js로 모든 페이지의 텍스트를 추출해 담당자 이름·소속·전달 안내 한글을 확인했다. 자동 E2E에서도 같은 항목을 검사한다.
- 모든 페이지를 PNG로 렌더해 표지, PC·모바일 섹션, 전체 원고, 고지, 푸터·페이지 번호를 검수했다.
- 최초 WOFF 부분 임베딩에서 복합 한글 글리프 누락을 발견했고 정적 TTF 전체 임베딩으로 수정한 뒤 21페이지를 다시 렌더해 누락·겹침·잘림이 없음을 확인했다.

## 반응형·접근성

Playwright가 320, 360, 390, 768, 1440px에서 4단계 모두 수평 오버플로가 없는지 확인한다. 390px와 1440px에서는 WCAG 2 A/AA·2.1 AA·2.2 AA axe 규칙을 검사한다. 고객 미리보기의 전화·오픈채팅은 편집 iframe에서 실행되지 않는다.

## 별도 운영 확인

- 실제 담당자 기기의 전화 앱과 카카오톡 로그인·오픈채팅방 활성 상태
- 실제 도메인 소유·DNS·게시 승인
- 광고심의 대상 여부와 조직 승인
- 배포 후 실사용 성능과 장기 브라우저 호환성

위 항목은 코드 테스트로 대신하지 않으며 이번 로컬 리빌딩에서 배포는 수행하지 않았다.
