# 전화·카카오톡 오픈채팅 직접 연결

이 파일의 경로는 이전 문서 링크 호환을 위해 유지합니다. **카카오톡 자동 전송 연동 계획은 현재 범위에서 제외합니다.**

## 현재 동작

- 전화 아이콘·전화 버튼: `contact.phone`을 검증해 `tel:` 링크를 생성합니다.
- 카카오톡 버튼: `contact.kakaoUrl`에 설정한 오픈채팅 초대 주소를 엽니다.
- 카카오 로그인 SDK, 앱 키, 메시지 API, 알림톡, 웹훅, 휴대전화 자동화, 서버 전송을 사용하지 않습니다.
- 링크를 눌러도 메시지를 작성하거나 발송하지 않습니다. 사용자가 열린 채팅방에서 직접 대화를 시작합니다.

유효한 초대 주소 형식은 `https://open.kakao.com/o/` 뒤에 초대 코드가 있는 HTTPS 주소입니다. 다른 도메인, 쿼리·프래그먼트, 포트·사용자 정보가 들어간 URL은 거부합니다. 링크 유효성 검사는 주소 형식 검사이며 실제 방의 존재·소유·활성 상태를 인증하지 않습니다.

## 설정과 점검

실제 원본은 `sites/<id>/site.json`입니다.

```json
{
  "contact": {
    "phone": "010-0000-1234",
    "kakaoUrl": "https://open.kakao.com/o/INVITE_CODE",
    "availableHours": "실제 운영 시간 입력"
  }
}
```

위 값은 형식 예시이며 실제 사용 가능한 연락처가 아닙니다. 조직이 확인한 번호와 초대 주소로 교체하세요. 대표 데모의 기존 담당자 정보는 보존하며 다른 고객에게 자동 복제하지 않습니다.

안드로이드·iPhone·PC에서 전화 앱/카카오톡 설치 여부에 따라 열리는 화면이 다를 수 있으므로 담당자의 실제 기기에서 확인합니다. PC 통화 앱이 없는 경우를 위해 전화번호를 텍스트로도 표시합니다. 오픈채팅이 열리지 않을 때 사용할 전화 연락도 유지합니다.

프로필·연락처 정보를 검토하지 않고 실제 연락 버튼을 시험하지 마세요. 자동 브라우저 테스트는 링크 값을 확인하고 편집 미리보기에서는 클릭을 차단합니다. 실제 상담 메시지를 시험 전송하지 않습니다.

## 개인정보와 종료된 API

고객 페이지에는 신청 입력란이 없습니다. 고객이 외부 앱으로 이동한 뒤 입력하는 정보는 그 서비스와 실제 운영자의 처리 범위에 해당하므로 담당 조직의 안내를 확인해야 합니다. 공개 채팅방에 주민등록번호·병력·계약서 원본을 남기지 않도록 안내합니다.

`/api/consultations`는 본문을 읽기 전에 HTTP 410으로 종료합니다. DB·이메일·웹훅을 호출하지 않습니다. 이전 DB 기록을 자동 삭제하지 않으며 보유·정리 결정은 별도 운영 절차입니다. 환경 변수에 이전 웹훅 주소가 남아 있어도 이 핸들러는 사용하지 않습니다.
