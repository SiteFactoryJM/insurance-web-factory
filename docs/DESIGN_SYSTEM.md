# Institutional Trust · calm-trust-v5

유퍼스트 해온지사의 상담 페이지. 짙은 색면, 낮은 채도, 명확한 구획과 타이포그래피를 사용한다. 버건디는 사용하지 않는다. 기존 실제 프로필 사진을 유지하며 경력·성과·자격을 임의로 만들지 않는다.

## 색상과 배치

6개 팔레트와 5개 구조를 독립적으로 선택하여 30개 조합을 제공한다. 색상 변경은 문구와 배치에 영향을 주지 않는다.

| 팔레트 | 명칭 | 강조색 | 어두운 배경 |
|---|---|---|---|
| navy | 미드나이트 네이비 | #2D4864 | #142131 |
| forest | 포레스트 그린 | #2B5544 | #142A20 |
| charcoal | 차콜 그레이 | #41464E | #1D2127 |
| teal | 딥 틸 | #235B63 | #112B30 |
| slate | 스틸 슬레이트 | #485868 | #202C39 |
| stone | 웜스톤 | #605744 | #302C25 |

모든 페이지의 푸터는 해당 팔레트의 `dark` 배경과 밝은 글자를 사용한다. 본문·입력·주요 버튼은 기본 18px, 보조 글씨·고지는 최소 16px이다. 사용자 요청에 따라 글자 크게 버튼을 제거했다. 브라우저 확대 및 200% 글자 확대는 계속 지원한다. 버튼 모서리는 2px이며, 카드 장식 대신 선과 구획으로 정보를 나눈다.

| 기존 URL 식별자 | 이름 | 첫 화면 / 구조 | 문구의 중심 |
|---|---|---|---|
| trust-blue | 신뢰의 기준 | 어두운 기업형 히어로 → 상담 분야 → 소개 | 현재 보장과 판단 기준 |
| warm-care | 사람과 대화 | 좌측 인물·우측 이야기 → 어두운 소개 → 준비 안내 | 상담 철학과 가족의 상황 |
| premium-navy | 선택의 기준 | 어두운 히어로·기준 메뉴 → 세 가지 기준 → 비교 분야 | 보장·예산·계약 조건 |
| clean-minimal | 한 장의 정리 | 제목·담당자·요약 행 → 점검 순서 → 항목별 행 | 보장 점검 리포트 |
| local-friendly | 바로 묻는 상담 | 담당자·주제 메뉴 → 상담 분야 → 신청 체험 | 상담 준비와 질문 선택 |

공통 폼·헤더·푸터를 공유하되 히어로 DOM, 섹션 순서, 상담 분야, FAQ 내용과 표기 형식은 다르다. 원본은 `sites/<id>/site.json`이며 생성 파일은 `npm run generate`로 갱신한다.

편집 가능한 Figma 방향 시안: https://www.figma.com/design/Zzdeta98Jlv3esNsAEArTG?node-id=2-8

기업형 데스크톱 첫 화면과 6개 색상의 방향을 시각화했다. 전체 사이트와 5종 배치의 실제 구현은 GitHub 소스 및 `/templates`에서 확인한다. Figma 스킬을 사용했고, Product Design은 설치되어 있으나 이 대화에서 실행 기능이 제공되지 않았으며 MiroMiro는 검색되지 않았다. 두 도구의 결과물로 표시하지 않는다.

Figma 작업 식별자: file `Zzdeta98Jlv3esNsAEArTG`, frame `2:8`, header `2:9`, hero `2:10`, principles `2:11`, palette `2:12`, footer `2:13`. Variables collection `VariableCollectionId:2:2`, colors `2:3`–`2:7`. 세부 노드는 파일에서 편집 가능하다.

## 검증

`npm run check`와 Playwright를 사용한다. 기본 5개 배치 × 320/360/390/768/1440px, 200% 글자 확대, 전체 30개 색상·배치 조합의 대비와 어두운 푸터, 조합 선택 왕복, 4단계 폼 미전송, 메뉴, 개인정보, JavaScript 비활성화 동작을 검사한다. 검사 결과는 해당 커밋의 Actions 실행을 기준으로 판단한다.

## 상담 안전 조건

무료 상담 신청은 분야 선택 → 상황 작성 → 연락 정보 → 최종 확인의 시연용 절차다. 입력을 저장·서버 전송·메일 발송·카카오톡 발송하지 않는다. 완료 화면은 실제 접수가 아니라고 명시한다. noindex, 보험 고지와 개인정보 안내를 유지한다. 카카오톡은 `docs/KAKAO_INTEGRATION.md`의 향후 계획에만 둔다.
