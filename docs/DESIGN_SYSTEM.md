# 디자인 시스템

## 모바일 우선 원칙

- 최소 지원 폭: 320px
- 본문 기본 크기: 16px
- 주요 입력창: 16px 이상으로 모바일 자동 확대 방지
- 터치 영역: 44px 이상
- 모바일 하단 고정: 전화 + 상담 신청
- 첫 화면 우선순위: 신뢰 문구 → 이름·소속 → 사진 → 상담 버튼
- 긴 한국어 문장은 `word-break: keep-all`과 충분한 행간 사용
- 장식보다 읽기와 행동 유도를 우선

## 글꼴

총 2개 계열만 사용합니다.

1. Pretendard: 본문·버튼·양식·기본 제목
2. Noto Serif KR: 원하는 사이트의 큰 제목만 선택적으로 사용

`headingFont` 값:

```text
pretendard
noto-serif-kr
```

## 템플릿

### trust-blue

정돈된 블루, 프로필 카드, 전문성과 안정감. 기본 추천안입니다.

### warm-care

베이지·그린과 곡선 프로필. 가족·건강 상담의 부드러운 인상에 적합합니다.

### premium-navy

네이비·골드, 어두운 배경, 경력과 전문성을 강하게 보여줍니다.

### clean-minimal

화이트·차콜, 에디토리얼 여백, 사진과 문구를 절제되게 강조합니다.

### local-friendly

틸·코랄, 지역 배지, 연락 접근성을 강조하는 생활 밀착형입니다.

## 사이트별 변경 가능한 값

- `template`
- `accentColor`
- `headingFont`
- 모든 콘텐츠 문구
- 프로필·로고·공유 이미지
- 지역 태그
- 섹션 표시 여부

## 공통 컴포넌트

헤더, 접근성 메뉴, 상담 버튼, 전문분야 카드, 상담 절차, FAQ, 상담 폼, 개인정보 링크, 하단 고지는 공통으로 유지합니다. 보험 관련 고지와 접근성을 임의로 제거하지 않습니다.
