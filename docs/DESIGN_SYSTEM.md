# 디자인 시스템

## 목표

보험설계사 소개 페이지는 화려함보다 다음 정보를 빠르고 분명하게 보여주는 데 초점을 둡니다.

1. 실제 상담가의 사진·이름·소속
2. 어떤 방식으로 상담하는지
3. 전화·카카오톡·인스타그램 연락 수단
4. 상담 과정과 자주 묻는 질문
5. 후기의 출처와 예시 여부
6. 준법·개인정보 고지

## 공통 신뢰 원칙

- 포인트 색은 청람, 포레스트, 미드나이트 네이비, 옥스블러드, 딥 틸처럼 채도가 낮고 명도가 안정된 계열을 사용합니다.
- 본문은 밝은 배경의 진한 글자 또는 어두운 배경의 밝은 글자로 구성합니다.
- 작은 본문 텍스트는 WCAG 2.1 AA의 4.5:1 대비를 목표로 합니다.
- 프로필 사진과 연락처를 첫 화면에서 찾을 수 있게 합니다.
- 과도한 그라데이션, 둥근 캡슐, 장식 아이콘, 이모지 사용을 피합니다.
- 이모지는 전화·카카오톡·인스타그램 세 연락 수단에만 사용합니다.
- 후기에는 실제 후기와 디자인 예시를 구분하는 고지를 제공합니다.

## 한글 글꼴

글꼴은 두 개만 사용합니다.

- Pretendard: 본문, 버튼, 데이터, 표와 모바일 UI
- Noto Serif KR: 휴먼 에디토리얼과 프라이빗 컨설팅의 제목

시스템 폰트 fallback을 제공하므로 외부 폰트가 늦게 로드돼도 내용을 읽을 수 있습니다.

## 다섯 가지 레이아웃

### 1. 인스티튜셔널 (`trust-blue`)

- 딥 네이비와 청람색
- 문서형 정보 위계와 번호 체계
- 프로필 카드와 상담 사실 정보를 병렬 배치
- 후기는 증빙 기록처럼 행 단위로 표시
- FAQ는 원장형 아코디언

### 2. 휴먼 에디토리얼 (`warm-care`)

- 깊은 포레스트 그린과 따뜻한 종이색
- 사진과 본문을 반으로 나누는 잡지형 히어로
- 대표 후기를 크게, 나머지를 편집형 목록으로 표시
- FAQ는 키보드 조작이 가능한 탭 패널
- 긴 상담 철학을 읽기 좋은 활자 중심 구성

### 3. 프라이빗 컨설팅 (`premium-navy`)

- 미드나이트 네이비와 절제된 브론즈
- 프로필 사진을 전체 배경으로 사용하는 시네마틱 히어로
- 설계사 정보는 별도 ID 카드에 표시
- 상담 절차는 세로 타임라인
- 후기와 FAQ는 어두운 상담 라운지 같은 구조

### 4. 리포트 미니멀 (`clean-minimal`)

- 오프화이트, 잉크 블랙, 옥스블러드
- 사진·번호·제목의 3열 보고서형 히어로
- 둥근 카드 대신 선과 표를 사용
- 서비스, 프로세스, 후기, FAQ를 번호가 있는 문서처럼 표시
- 정보량이 많은 설계사에게 적합

### 5. 모바일 컨시어지 (`local-friendly`)

- 딥 틸과 스톤 컬러
- 연락 수단을 가장 먼저 보여주는 모바일 상담 데스크 구조
- 프로필은 예약 카드 형태
- 상담 분야는 선택 메뉴 보드
- 후기는 사례 카드, FAQ는 한눈에 읽는 전체 노출 카드

## 모바일 규칙

- 최소 화면 폭 320px에서 가로 스크롤이 없어야 합니다.
- 입력 글자 크기는 16px 이상으로 두어 모바일 브라우저 자동 확대를 방지합니다.
- 전화·카카오톡·인스타그램은 하단 고정 3열 CTA로 제공합니다.
- 데스크톱용 테마 선택 플로팅 UI는 860px 미만에서 숨기고 `/templates` 페이지로 대체합니다.
- 주요 버튼과 링크는 최소 높이 약 44px 이상을 유지합니다.

## 사용자별 변경 범위

- 사진과 크롭 위치
- 레이아웃 ID와 포인트 색
- 이름·소속·등록번호·활동 지역
- 소개 문구·상담 원칙
- 상담 분야·상담 과정
- 후기·FAQ 내용 및 노출 여부
- 상담 카드 전송 방식
- SEO 및 준법 고지
