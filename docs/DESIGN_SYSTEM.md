# Calm Trust — 2026 보험 상담 페이지 디자인 시스템

## 방향

실제 상담자를 중심에 두고, 필요한 정보를 충분히 보여주며, 가입을 재촉하지 않는 상담 중심 디자인. 2026-09-08 개편에서 기존 장식 중심 5개 레이아웃의 구현은 교체하고, 프로필·소속·운영 정보·멀티사이트 구조·5개 URL 식별자는 유지했다. 새로운 5안은 하나의 마스터와 공통 컴포넌트를 공유한다.

폰트는 Pretendard 계열과 한글 시스템 폰트 대체 경로를 사용한다. CDN이 실패해도 내용과 조작이 유지되어야 한다. 원본 폰트 파일을 저장소에 복제하지 않는다. 호환성을 위해 이전 `headingFont`, `accentColor` 필드는 유지하지만, 이번 마스터의 서체와 주요 버튼 색상은 공통 토큰으로 고정한다.

`글자 크게`는 루트 글자를 112.5%로 조정한다. 본문 약 20.25px, 보조 글씨 18px가 되며 브라우저 기본 글자 확대도 차단하지 않는다. 설정은 현재 페이지에서만 유지하고 브라우저 저장소를 사용하지 않는다.

## 정보 구조

담당자 확인 → 상담 분야 → 페이지 중간의 상담 신청 → 상담 원칙과 담당자 정보 → 상담 절차 → 선택적 후기 → FAQ → 운영·고지 정보.

대화 중심형은 소개를 상담 분야 앞에 둔다. 정보 최소형은 후기 영역을 노출하지 않는다. 비어 있는 경력·등록번호·후기를 메달이나 가상의 숫자로 대신하지 않는다. 실제 운영 페이지에서는 `isExample: true` 후기를 출력하지 않는다. 데모 후기에는 각 항목과 섹션 양쪽에서 실제 후기가 아님을 명시한다.

## 공통 UX

한 개의 주요 행동은 `상담 요청하기`다. 전화·카카오톡·인스타그램을 같은 비중으로 나열하지 않는다. 데모에서는 외부 연락 링크를 실행하지 않는다. 모바일 하단 버튼은 첫 화면·신청 영역·푸터·입력 포커스·가상 키보드 상태를 고려해 숨긴다. 화면 아래 안전 영역을 확보한다.

메뉴와 FAQ는 기본 HTML details/summary를 사용한다. 포커스 표시, 본문 바로가기, 오류 위치 안내, 단계 변경 포커스 이동, 키보드 조작을 유지한다. 작은 화면에서 세로 스크롤은 허용하되 이름·소속·고지 문구를 자르지 않는다. 모션 감소 설정을 존중한다.

신청 흐름은 분야 → 상황(선택) → 연락 정보 → 최종 확인이다. 잘 모르는 분야도 선택할 수 있고, 이전 단계로 돌아가 수정할 수 있다. 개인정보 입력은 데모 확인용이며 전송/저장 기능이 아니다.

## 구현 위치

- `src/render/styles.ts`: 공통 토큰과 반응형 규칙
- `src/render/design-system.ts`: 샘플 메타데이터와 기본 상담 분야
- `src/render/calm-page.ts`: 공통 페이지 및 목적별 변형
- `src/render/shared.ts`: 헤더·신청·고지·모바일 CTA
- `src/render/client-script.ts`: 메모리 내 데모 상호작용
- `sites/<id>/site.json`: 실제 설계사 정보의 단일 원본
