# Clear Human 디자인 시스템

담당자 소개, 상담 범위, 직접 연락 방법을 차분하고 명확하게 보여 주는 공통 디자인 시스템입니다. 디자인 정본은 Figma `보험설계 2026 · Clear Human`의 `CH2/Navy/*` 컴포넌트이며, 실제 렌더링 수치는 `src/render/clear-human-styles.ts`에 있습니다. 이 스타일은 공통 스타일의 마지막 레이어로 적용됩니다.

Figma 원본 파일은 이 개선으로 수정하지 않았습니다. 사용자 요청에 따라 반영한 `balanced-v2` 타이포그래피·공간 규칙은 원본 팔레트·컴포넌트 대응을 유지한 소비자 화면의 명시적 오버라이드입니다. `data-design-version="clear-human-v1"`은 호환 식별자로 유지하고, 고객 첫 화면의 `data-typography-version="balanced-v2"`로 이 적용을 식별합니다.

## 색상

5개 화면 구성과 6개 팔레트를 독립적으로 조합해 30개 미리보기를 제공합니다. 팔레트 변경은 원고, 담당자 정보, 섹션 순서를 바꾸지 않습니다.

| ID | 이름 | 강조색 | 본문색 | 옅은 배경 | 구분선 |
|---|---|---|---|---|---|
| `navy` | 미드나이트 네이비 | `#2D4864` | `#172A3D` | `#E8EDF3` | `#CDD6E0` |
| `forest` | 포레스트 그린 | `#2B5544` | `#142A20` | `#EAF3ED` | `#D1DED5` |
| `slate` | 스틸 슬레이트 | `#485868` | `#24323F` | `#E5E9ED` | `#CDD4DB` |
| `charcoal` | 차콜 그레이 | `#41464E` | `#1D2127` | `#ECEFF3` | `#D7DDE5` |
| `teal` | 딥 틸 | `#235B63` | `#112B30` | `#E7F2F3` | `#CDDDE0` |
| `stone` | 웜 스톤 | `#605744` | `#302C25` | `#F2EDE2` | `#DDD6C9` |

`paletteStyle()`은 `--accent`, `--ink`, `--muted`, `--paper`, `--tint`, `--line`, `--input`, `--detail`, `--surface`, `--on-brand`와 채널 색을 내보냅니다. 어두운 이름 카드에서는 이름과 전화번호에 `--on-brand`, 직함·소속·상담 시간에 각 팔레트의 `--detail`을 사용합니다. 여섯 팔레트 모두 이 보조 글자와 카드 배경의 대비가 4.5:1 이상입니다.

카카오톡 오픈채팅 버튼은 채널 식별을 위해 팔레트와 별도의 고정 색을 사용합니다. 상태·채널 의미가 있는 색을 장식용으로 바꾸지 않습니다.

## 화면 구성

| ID | 이름 | 첫 화면 | 상담 분야 | 기본 섹션 흐름 |
|---|---|---|---|---|
| `trust-blue` | 신뢰의 기준 | 인물 사진과 이름 카드 | 목록 | 상담 분야 → 소개 → 과정 → 후기 → FAQ → 연락 |
| `warm-care` | 사람과 대화 | 인물 사진과 이름 카드 | 카드 | 소개 → 상담 분야 → 후기 → FAQ → 과정 → 연락 |
| `premium-navy` | 선택의 기준 | 중앙 원고와 인물·이름 카드 | 균등 2열 | 상담 분야 → 과정 → 소개 → FAQ → 연락 |
| `clean-minimal` | 한 장의 정리 | 중앙 원고와 인물·이름 카드 | 카드 | 상담 분야 → 과정 → FAQ → 소개 → 연락 |
| `local-friendly` | 바로 묻는 상담 | 원고와 장면 이미지 | 카드 | 상담 분야 → 연락 → FAQ → 소개 → 과정 |

고객 본문은 데스크톱에서 최대 1120px로 가운데 정렬합니다. FAQ 목록은 880px, editorial 소개 본문은 720–800px, 직접 연락 패널은 780px 안에서 읽습니다. 섹션 상하 여백은 데스크톱 64px, 태블릿 48px, 모바일 40px입니다. 제목과 설명은 같은 중앙 묶음에 두고 12px 안팎으로 붙이며, 다음 콘텐츠와의 간격은 28px 안팎으로 둡니다. 긴 한국어는 줄임표나 `line-clamp` 없이 전부 표시합니다.

상담 분야는 목록형에서 데스크톱 2열의 컴팩트 항목으로 묶습니다. 각 항목은 번호와 제목·설명을 한 묶음으로 읽고, 긴 한국어도 잘리지 않게 둡니다. list/cards/split 모두 모든 항목 위에 같은 1px 구분선을 두어 줄의 시작점을 통일하고, hover/focus-within에서는 레이아웃을 움직이거나 그림자를 키우지 않은 채 위쪽 3px 강조선만 나타냅니다. `premium-navy`의 첫 항목도 별도 박스로 만들지 않아 같은 행 규칙을 따르고, `local-friendly`의 왼쪽 강조선처럼 테마 고유 장식은 모든 항목에 동일하게 적용합니다. 정보 카드 자체는 클릭 대상으로 오해되지 않도록 포인터·과도한 상승 효과를 사용하지 않습니다. 650px 이하에서는 한 열로 전환합니다.

첫 화면은 원고와 사진·이름 카드 묶음의 가장자리를 맞춥니다. portrait 형식에서는 사진과 카드를 같은 폭으로 맞추고 사진의 3:4 비율과 최대 폭을 유지합니다. statement 형식은 가로 사진·카드 조합의 전체 폭을 별도로 적용합니다. 이름 카드만 내부 텍스트를 가운데 정렬해 좌우 여백을 균형 있게 두며, 이름과 전화번호를 먼저 읽히게 하고 나머지 사실 정보는 낮은 강조로 구분합니다.

## 타이포그래피와 접근성

첫 화면 제목은 최대 56px/1.25, 섹션 제목은 최대 38px/1.35를 기준으로 하며 모바일 섹션 제목은 28–30px입니다. 카드·과정 제목은 22–24px/1.45, 본문은 데스크톱 19px와 모바일 18px/1.65, 보조 글자와 고지는 16px/1.6 이상을 기준으로 합니다. 담당자 이름은 데스크톱 44px, 모바일 36px, 소속은 18px, 전화번호는 데스크톱 26px·모바일 22px으로 읽기 순서를 만듭니다.

과정은 데스크톱에서 숫자·제목·설명을 함께 둔 동등한 3단계 패널로 보이고, 모바일에서는 세로로 읽습니다. editorial 소개는 중앙 제목과 720–800px의 좌측 정렬 본문에 집중하고, 프로필형은 사진과 본문의 2열 구성을 유지합니다. 소개 본문 아래에는 별도 카드 박스를 늘리지 않고 `상담 원칙`을 제목 1개와 짧은 설명 1개로 이어 붙입니다. 제작 화면의 담당자 소개 16개 문구에는 각각 다른 상담 원칙 문구와 `01`~`16`의 미세한 타이포그래피 배치를 함께 제공하며, 모바일에서는 모두 한 열의 같은 읽기 순서로 돌아옵니다. 원칙 문구는 이해·유지 조건·가입 후 확인 절차·충분한 설명을 다루되 보험금 지급이나 장기 관리 결과를 보장하는 표현은 사용하지 않습니다. 담당자 이름·소속·직함·상담 시간처럼 행동 직전에 다시 필요한 사실 정보는 연락 패널로 일원화하고, 설계사 등록번호와 상담 지역처럼 소개 맥락에 필요한 보조 정보만 소개 본문에 남길 수 있습니다. 헤더의 이름 옆 보조 라벨에는 일반 문구 `보험상담` 대신 실제 `agent.title`을 표시합니다. FAQ는 중앙 제목 아래 880px 목록으로, 연락 영역은 중앙 제목·설명과 직접 연락 패널 순서로 배치합니다. 연락 패널은 `담당자`와 `소속 · 직함`을 한 행, `전화번호`와 `상담 시간`을 다음 행에 두고 이메일·팩스가 있으면 이어 붙이며 개인정보·데모 고지는 좌측 정렬을 유지합니다.

브라우저 200% 글자 확대, 키보드 포커스, 본문 바로가기, 이미지 대체 텍스트를 지원합니다. 모바일 원고는 650px 이하에서 사용하며 별도 원고가 없으면 PC 원문을 줄이지 않고 표시합니다.

공식 보험·금융 사이트에서 공통으로 확인되는 넓은 여백, 낮은 채도의 바탕, 실제 조직명과 담당자 정보의 우선 표기 원칙을 반영합니다. 로고 파일이 없을 때 임의의 대체 로고를 만들지 않고, 경력·성과·자격·후기를 생성하지 않습니다.

## 연락과 제작 경계

고객 페이지의 주요 연락 버튼은 `tel:` 전화와 카카오톡 오픈채팅입니다. 이메일과 팩스번호는 선택 정보로 연락 패널과 푸터에 표시하며, 이메일은 `mailto:` 링크, 팩스는 번호 안내로 제공합니다. 입력 폼, 서버 저장, 자동 메시지, 웹훅은 없습니다. 이전 `/api/consultations`는 요청 본문을 읽지 않고 HTTP 410을 반환합니다.

제작 경로는 `/studio` 하나입니다. 디자인과 문구 선택 → 실제 정보 입력 → 확인하고 저장의 3단계이며, 768px 미만에서는 제작 안내만 표시합니다. 미리보기에서는 전화·오픈채팅 이동을 막고 사용자 입력을 외부로 보내지 않습니다.

## 검증

`npm run check`와 `npm run test:e2e`를 사용합니다. 고객 페이지는 320·360·390·768·1440px, 200% 글자 확대, 5개 구성×6개 팔레트, 긴 한국어, 모바일 하단 연락 버튼, 이름 카드 대비와 프로필 대체 텍스트를 확인합니다. 실제 실행 결과는 [REBUILD_VALIDATION.md](REBUILD_VALIDATION.md)에 기록합니다.
